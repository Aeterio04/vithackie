KAWACH Deployed-Site Simulator

Mock server exercising edge cases found in deployed web environments:

  • /waf-blocked - Simulates Cloudflare/AWS WAF challenge against headless bots; passes on desktop Chrome UA or X-QA-Token: test-qa-token-123.
  • /api/head-405 - Returns 405 Method Not Allowed on HEAD, 200 on GET (tests GET range fallback).
  • /api/flaky-gateway - Returns 502 Bad Gateway on first hit, recovers to 200 OK on retry.
  • /consent-banner - Cookie consent banner overlay blocking underlying actions.
  • /theme-test - Dark/light mode theme toggle button with SVG icon, aria-label, CSS custom properties, and localStorage.
  • /spa - Client-side hash routing SPA.
